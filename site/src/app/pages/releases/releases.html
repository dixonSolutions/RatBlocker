How releases will work

Tagged releases will carry the artifacts above with their checksums, and the filter database will be signed so an update can be verified before it is activated. The update path already stages a download, proves it compiles into a working engine, and only then swaps it in — with the previous database kept for rollback.

The Chromium extension is signed with a project key and self-hosted, so updates arrive through an update manifest rather than a store. The Firefox extension needs Mozilla's signature for release Firefox; Gecko forks can take it unsigned.
